## C2 — Committed Answer Match

### Stage 1 / CANDIDATE QUALITY RECORD

Trust problem: a puzzle author could change the reference answer after seeing a guess, or privately decide that a semantically equivalent answer loses. Product: a public, bounded one-guess meaning-match game. A commits an answer before B submits a guess; A then reveals the same preimage; validators judge answer equivalence in the frozen clue context. Ordinary string comparison misses paraphrases, while an author-operated server controls both target and judgment. Commitment prevents retrospective target substitution; GenLayer supplies shared semantic adjudication. No money, prizes, identity/achievement claim, off-chain puzzle origin or private-document verification exists.

Actors: A author owns clue/commitment at create and reveal; assigned B alone submits one guess; anyone evaluates/retries/expires. Secret answer is a native game choice, NOT evidence of an external fact. Every semantic input is public before evaluation. Salt protects the unrevealed choice; it is not a signature, wallet secret or proof of external reality. Withholding produces VOID, never an invented winner. A can choose a bad clue: ambiguity remains UNKNOWN/VOID.

Source/feasibility: no fetch, credential, uploaded document or asserted physical event. Validators deterministically check the committed preimage and independently compare the two texts. New work: commitment-before-guess, phase-bound reveal, transaction-time expiry and non-punitive void; shared JSON/CAS/journal reused. Closest repository vulntriage-dao roadmap mentions encrypted evidence commit/reveal, but this uses no external claim or confidentiality service and resolves a native game target, not vulnerability validity. Closest portfolio C10 has repeated alternating word-category scoring; C2 has one binding preimage and delayed disclosure, no turn chain/score. Originality risk medium, flagged for independent audit. KEEP for review, not APPROVED.

Evidence plan: display full commitment context, guess, revealed preimage, recomputed digest, accepted equivalence label and immutable version. Anyone can recompute all nonsemantic state and inspect exact evaluator inputs. Easy protocol <=7 mutations; hard semantic agreement and user preimage loss. Simplest fallback: safe VOID, no alternative adjudicator or hidden rescue. Assumption: users want a neutral paraphrase-aware guessing game.
